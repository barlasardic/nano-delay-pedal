# Arduino Delay Pedal

A project to develop an Arduino-based guitar delay pedal.

Currently, the project consists only of a circuit schematic created in KiCad. The circuit has not yet been physically assembled or tested.

## Circuit Schematic

The KiCad schematic file is included in this repository. Open the project in KiCad to view or edit it.

## Project Status

- [x] Draw the initial circuit schematic
- [x] Review the schematic
- [x] Finalize components and their values

## Goal

Develop a delay pedal that adds delayed repeats to the guitar signal and document the design process in this repository.

The role of the Arduino and the effect specifications will be documented as the design progresses.

## Note

The current schematic is an initial draft. Connections and component values may change during development.
